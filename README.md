A compact alpha-beta chess engine in Python that fits in 4 KB: negamax search with a transposition table, quiescence, piece-square tables and a fixed node budget (never a clock, so every replay plays the same moves). It plays the make.fun house gauntlet over the env's HTTP API.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8080 python3 main.py
```
